# CLAUDE.md — LangFlow Railway

One-click LangFlow deployment on Railway.

## What it is

A Railway template that deploys a [LangFlow](https://github.com/logspace-ai/langflow) instance — a visual framework for building LLM pipelines and flows.

## Deploy

Use the Railway button in the README, or:

```bash
pip install -r requirements.txt
langflow
```

No code changes needed — this is a deployment wrapper around the upstream LangFlow package.
